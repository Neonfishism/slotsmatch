# 世界赛选手评分复核

复核日期：2026-11-10。覆盖 S11–S14 的448份赛季选手档案、2688项属性、88份赛季战队档案。评分表示**对应届世界赛表现的游戏估值**，不是全年能力、职业生涯排名或官方能力值。名单、原队、位置及原始比赛统计未改动。

## 发现与修订

旧模型把原队强度用作六项属性的共同底分，因此冠军队成员、少量上场的替补容易一同获得高分；较弱队伍中的突出选手又被整体压低。部分人工档案多项达到99，挤压了选人时的属性差异。综合分的计算权重也与排阵引擎不完全一致。

本次改为同届、同位置的个人表现百分位；原队和对手强度仅作小幅修正。所有表现与风格修正统一接受短样本收缩，人工专长目标每份最多两项。选手综合分与排阵引擎使用完全相同的本职权重及舍入方式；历史对手战队也按同一阵容公式重新估值。

| 指标 | 修订前 | 修订后 |
| --- | ---: | ---: |
| 95分及以上的综合分档案 | 50 | 4 |
| 95分及以上的单项属性 | 273 / 2688（10.2%） | 56 / 2688（2.1%） |
| 99分单项属性 | 61 | 6 |
| 综合分范围 | 48–99 | 68–96 |
| 综合分平均值 | 75.13 | 80.84 |

平均值上升与顶端收缩同时发生：强队不再集体接近满分，小赛区选手也不再只因原队基础分低而被压至50–60分。新旧数字不应当作同一量尺直接比较。

## 可复现口径

1. 在本届、本职位置内计算15分钟经济差、补刀差、DPM、伤害效率、KDA、参团率、视野和存活表现的百分位。伤害效率为平均伤害占比除以平均所得经济占比；存活代理采用单位时间死亡频率的相反数。
2. 六维围绕岗位基准变化；对线使用65%经济差与35%补刀差，其他维度按对应指标加权。原队修正为`(原队内部参考强度−80)×0.12`；对手修正为`(对手平均参考强度−80)×0.20`并限制在±5，另减去`2×入围赛出场占比`。
3. 少量该届风格修正为2–5分，有限的专长目标只表达操作、团战、运营等具体长处。无“夺冠即稳定99”规则。所有修正按`n/(n+4)`收缩至岗位基准，最后取整并限制在42–99。
4. 综合分使用引擎的本职位置加权分，先保留一位小数，再四舍五入为卡面整数。生成器按JavaScript的累加和舍入次序处理，避免浮点边界造成卡面与排阵不一致。
5. 历史队伍各位置选择出场最多者，同局数按ID排序；剩余人员中出场最多者作为替补。战队强度使用引擎相同的几何平均、同队熟练度、野辅协同和替补加成公式。原参考强度只留作评分模型内部的小幅背景修正，不再直接作为模拟对手的最终分数。

运行 `python scripts/worlds-build.py` 可由本地原始缓存重新生成；`--output <path>` 可单独生成候选文件。模型、岗位基准和全部有限人工调整均在该脚本内列明。自动校验覆盖448份档案的综合分一致性、88队的阵容强度一致性、短样本与属性满分异常；另逐字段比较原始备份，确认人物身份、赛季、战队、赛区、位置和 `sourceStats` 全部保留。

## 来源与边界

比赛统计及名单采用 [Oracle’s Elixir比赛数据](https://lol.timsevenhuysen.com/matchdata/)；镜像、逐届赛事核对入口、日期过滤及原始字段说明见 [数据口径](./data-notes.md)。实际纳入的世界赛记录未出现关键统计缺失，不把缓存内已排除的资格赛缺项误判为选手缺失数据。

拳头对 [Finals MVP奖项的说明](https://nexus.leagueoflegends.com/en-us/2018/10/the-2018-finals-mvp-award/)着重决赛贡献，因此该奖项可帮助识别关键场次特点，不能自动证明整届所有能力都达到满分。人工修正仅是玩法设计判断，不冒充官方评分。

统计代理受英雄选择、版本、资源分配、队友和对手影响；尤其辅助补刀、坦克伤害、指挥职责无法由这些字段完整测量。入围赛与正赛的强度差也只做粗粒度修正；短样本收缩能降低偶然值影响，不能创造未知信息。模型允许某些个体排序与观众印象或最终名次不同，后续如有新证据，应修订具体指标或专长依据，避免按名气直接重排整张榜单。
