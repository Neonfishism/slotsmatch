# WORLDS DRAFT / 忍道 NINDO

默认页面为 **S赛事版 WORLDS DRAFT**，首次抽取前必须为战队命名。已移除忍村切换及选手档案入口；原忍村代码在`?demo=nindo`保留，两个版本独立存档。

S赛版支持S11–S14四届世界赛、88份战队档案、448份赛季选手档案。每轮重新随机赛季和赛区，仅从本轮该区当届全部实际上场选手中抽6选1；成功签约后抽下一轮赛签。六轮组成上路／打野／中路／下路／辅助与一名替补，可以跨年跨区组队，同一人物的跨年版本不能重复签约，已签约成员保留各自赛季数值。所有队伍统一出征2026（S16）世界赛，按第六轮赛区归属模拟瑞士轮及淘汰赛，对手使用S14历史阵容。首页和结算页展示服务器共享排行榜，成绩经服务端校验并持久保存至SQLite。候选重抽、取消、换位和刷新均不更换本轮赛签。六维数值为参考比赛统计设计的游戏估值。

S赛玩法、评分与模拟边界见 [WORLDS_DESIGN.md](./WORLDS_DESIGN.md)，名单和来源见 [src/worlds/data-notes.md](./src/worlds/data-notes.md)。`src/worlds/App.jsx`、`data.js`、`engine.js`、`worlds.css`分别对应界面、档案、规则和视觉；`src/entry.jsx`选择版本。

以下保留原忍村版说明。


火影忍者题材的四人小队选秀原型：随机抽取忍村与剧情时期，从对应时期候选中逐轮招募忍者，分配队长、侦察、突破、支援四个职责，挑战二十次 S 级任务。

## 本地运行

需要 Node.js 24+（排行榜使用内置SQLite）。完整网站运行与公网部署见[DEPLOYMENT.md](./DEPLOYMENT.md)。

```sh
npm install
npm run build
npm start
```

打开`http://127.0.0.1:3001`。开发时保持后端运行，另开终端执行`npm run dev`。生产构建与规则检查：

```sh
npm run build
npm test
```

## 已实现

- 五大忍村、85 位忍者（木叶32／砂隐12／雾隐15／云隐14／岩隐12）、八维能力档案与职责适配。
- 新局从中忍考试、晓组织对抗、五影会谈、第四次忍界大战4种剧情时期抽签，连续两签不重复；再匹配该时期的合法忍村。历代忍者保留在档案室和旧局，合计229份能力档案、13个档案组合，新局开放其中8个剧情组合。
- 四种剧情时期长期概率相同，每局数量不固定；早期池目前只有木叶，因此忍村概率不均匀。
- 每轮从当前忍村与时期未入队的人物中随机抽取6位，横向并列、八维逐行对齐；固定属性列、最高值高亮，点击属性可排序。
- 候选由本局种子、忍村、时期、抽签序号和已选成员确定，刷新保留同批候选；换轮或重抽忍村时重新抽取。
- 点击忍者后弹窗选择职责，同时展示四职适配，已有成员的位置禁止覆盖；取消不会消耗选人机会。
- 忍村与时期以橙色、紫色等宽双滚轮并排展示；首轮、换轮与重抽高亮并同步快速滚动 1.6 秒，末段逐渐减速，动画期间暂停招募。
- 四轮选人，同一人物的不同阶段版本也不可重复入队；忍村可重复；自由模式两次重抽。
- 20 次 S 级任务，每次等概率抽取潜入／追踪／强袭／护送，数量不固定；任务类型改变职责评分权重，逐项成败解释。
- 右侧委托显示本局实际任务分布；任务类型与临场波动随挑战种子固定，整体判定门槛小幅提高2分。
- 上海日期的每日同签挑战；种子链接复现自由挑战。
- 本地自动存档、最近 12 次战报、文本分享及同签邀请。
- 刷新直接恢复当前局，不重新播放抽村；自由模式点击“随机新一局”生成新签，每日模式“重试今日挑战”保留当日固定签。
- 桌面与手机布局，键盘操作和原生模态框。

## 数据口径

八维框架参考官方资料书的忍、体、幻、贤、力、速、精、印。**本原型的 0–100 数值全部是参考原作特长的游戏估值，不是官方能力数值或官方战力排名。** 特别是后期登场角色，没有统一时点、覆盖全员的官方八维数据，不能把自行补值包装成官方统计。

角色按出身忍村归档，跨时代集结；离村身份、剧情阶段与形态在档案中注明。历代池保留原85人常规档案；大战池收录部分明确标注的秽土复刻，数值不计不死与自动恢复。排除六道、十尾、最终八门、轮回眼佐助与双神威卡卡西等极端形态。人物插画为本项目绘制的简化 SVG 头像。

详细算法、参数与来源见 [GAME_DESIGN.md](./GAME_DESIGN.md)。
